# 🚀 Welcome to GnosisEngine

GnosisEngine is an interactive AI Notes Engine designed for rapid learning, technical documentation, and visual system architectures.

<!--truncate-->

## Key Capabilities

- **Interactive Study Notes**: Native support for rich interactive notes and documentation.
- **Embedded Mermaid Diagrams**: Render complex flowcharts, sequence diagrams, and class models directly inside notes.
- **AGY CLI Skill Integration**: Automated technical curriculum generation powered by AI agent skills.
