## 📖 Key Glossary

- **Sliding Window:** Maintaining a dynamic contiguous subarray window using two pointers (`l` and `r`) to process substring/subarray constraints in $O(N)$ time.
- **Two Pointers:** Using two indexes iterating towards each other or at different speeds to solve linear array/string problems without nested loops.
- **Monotonic Stack:** A stack data structure whose elements are strictly increasing or strictly decreasing, enabling $O(N)$ discovery of nearest greater or smaller elements.
- **Topological Sort:** Linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every directed edge $u \to v$, node $u$ comes before $v$.
- **Memoization (Top-Down):** Recursively solving subproblems and caching results in a map or array to avoid redundant calculations.
- **Tabulation (Bottom-Up):** Iteratively populating a table from base cases up to the target state.
