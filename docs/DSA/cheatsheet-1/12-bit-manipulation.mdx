# 🔢 Bit Manipulation Patterns & Hacks

## 🎯 Learning Objectives
- Understand JavaScript bitwise operators and V8 32-bit signed integer conversions.
- Master essential bit tricks: clearing lowest set bit (`n & (n-1)`), isolating lowest bit (`n & -n`), and XOR properties.
- Generate all $2^N$ subset combinations using bitmask shifting.
- Solve LeetCode problems like *Single Number*, *Counting Bits*, and *Subsets*.

---

## 💡 Core Concept & Operators in JavaScript

JavaScript converts 64-bit IEEE 754 floating point numbers into **32-bit signed integers** prior to executing any bitwise operations.

| Operator | Name | Example (`a = 5` (0101), `b = 3` (0011)) | Result |
|---|---|---|---|
| `&` | AND | `5 & 3` (0101 & 0011) | `1` (0001) |
| `\|` | OR | `5 \| 3` (0101 \| 0011) | `7` (0111) |
| `^` | XOR | `5 ^ 3` (0101 ^ 0011) | `6` (0110) |
| `~` | NOT | `~5` (~0000...0101) | `-6` |
| `<<` | Left Shift | `5 << 1` | `10` |
| `>>` | Sign-propagating Right Shift | `-5 >> 1` | `-3` |
| `>>>` | Zero-fill Right Shift | `-5 >>> 1` | `2147483645` |

## 🛠️ The 5 Legendary Bit Hacks

```javascript
// 1. Check if number is odd
const isOdd = (n) => (n & 1) !== 0;

// 2. Check if power of 2
const isPowerOfTwo = (n) => n > 0 && (n & (n - 1)) === 0;

// 3. Clear lowest set bit (Brian Kernighan's Algorithm)
const clearLowestSetBit = (n) => n & (n - 1);

// 4. Isolate lowest set bit
const isolateLowestSetBit = (n) => n & (-n);

// 5. Swap two numbers without extra variable
let a = 5, b = 9;
a = a ^ b;
b = a ^ b; // b becomes original a
a = a ^ b; // a becomes original b
```

## 💻 Runnable JavaScript Examples

### Problem 1: Single Number (LeetCode 136)
*Given a non-empty array of integers `nums`, every element appears twice except for one. Find that single one.*

```javascript
function singleNumber(nums) {
  let result = 0;
  for (const num of nums) {
    result ^= num; // x ^ x = 0, x ^ 0 = x
  }
  return result;
}

// Verification
console.log(singleNumber([4, 1, 2, 1, 2])); // Output: 4
```

### Problem 2: Single Number III (LeetCode 260)
*Two elements appear once, all other elements appear twice. Find the two elements.*

```javascript
function singleNumber3(nums) {
  // 1. XOR all numbers -> result is (a ^ b)
  let xorSum = 0;
  for (const num of nums) xorSum ^= num;

  // 2. Find the lowest set bit where a and b differ
  const diffBit = xorSum & (-xorSum);

  let num1 = 0, num2 = 0;
  for (const num of nums) {
    // Partition numbers into two groups based on diffBit
    if ((num & diffBit) !== 0) {
      num1 ^= num;
    } else {
      num2 ^= num;
    }
  }

  return [num1, num2];
}

// Verification
console.log(singleNumber3([1, 2, 1, 3, 2, 5])); // Output: [3, 5]
```

### Problem 3: Subsets via Bitmask Iteration (LeetCode 78)

```javascript
function subsetsBitmask(nums) {
  const n = nums.length;
  const totalSubsets = 1 << n; // 2^n combinations
  const result = [];

  for (let mask = 0; mask < totalSubsets; mask++) {
    const subset = [];
    for (let i = 0; i < n; i++) {
      // Check if i-th bit is set in mask
      if ((mask & (1 << i)) !== 0) {
        subset.push(nums[i]);
      }
    }
    result.push(subset);
  }

  return result;
}

// Verification
console.log(subsetsBitmask([1, 2, 3])); // Generates all 8 subsets
```

## ⚠️ Common Pitfalls
- **Operator Precedence:** Bitwise operators (`&`, `|`, `^`) have LOWER precedence than comparison operators (`==`, `<`). Always wrap bitwise expressions in parentheses: `if ((n & 1) === 0)` NOT `if (n & 1 === 0)`.
- **Large Integers Bit Shift:** In JS, `1 << 31` becomes negative (`-2147483648`), and `1 << 32` wraps around to `1`. Bitwise ops strictly cap at 32-bits.

## ✅ Quick Reference / Cheatsheet

```text
n & (n - 1)   -> Drops rightmost 1-bit (Counts 1-bits in O(k) steps)
n & (-n)      -> Extracts rightmost 1-bit
x ^ x = 0     -> Duplicate cancellation
1 << i        -> Mask with 1 at index i
(mask & (1 << i)) !== 0 -> Checks if i-th bit is set
```
