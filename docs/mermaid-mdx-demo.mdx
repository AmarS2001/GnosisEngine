# 📊 MDX & Mermaid Diagram Demo

This page demonstrates that **Mermaid diagrams render directly in `.mdx` files** seamlessly alongside React components, tabs, admonitions, and cards in **GnosisEngine**.

---

## 🎨 Interactive MDX Mermaid Flowchart

The diagram below is rendered directly inside an `.mdx` document file:

```mermaid
graph LR
    User["👤 Developer / Student"] -->|Writes .mdx file| MDX["📄 Markdown + React MDX"]
    MDX -->|Parses Mermaid Code block| Mermaid["📊 Docusaurus Theme Mermaid"]
    Mermaid -->|Render SVG| UI["✨ Interactive UI & Grid Background"]

    style User fill:#818cf8,stroke:#4f46e5,color:#fff,stroke-width:2px
    style MDX fill:#06b6d4,stroke:#0891b2,color:#fff,stroke-width:2px
    style UI fill:#10b981,stroke:#059669,color:#fff,stroke-width:2px
```

---

## 🚀 Sequence Diagram in MDX

You can also include sequence diagrams in `.mdx` files:

```mermaid
sequenceDiagram
    autonumber
    actor Dev as Learner
    participant MDXDoc as MDX Page
    participant Plugin as Theme Mermaid Plugin
    participant Browser as Web Browser

    Dev->>MDXDoc: Open MDX document
    MDXDoc->>Plugin: Process mermaid block
    Plugin->>Browser: Render SVG diagram
    Browser-->>Dev: Interactive visual chart displayed!
```
